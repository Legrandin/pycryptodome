# Security policy

## Reporting a vulnerability

Please do not report security vulnerabilities in public GitHub issues or pull requests.

Send an email to **security@pycryptodome.org**, with a description of the problem,
the affected versions, and if possible code or data that reproduces it.

## Supported versions

| Version | Security fixes |
| ------- | -------------- |
| 4.x (latest release) | Yes |
| 3.x (`pycryptodome` and `pycryptodomex`) | Important fixes only |
| Older | No |
