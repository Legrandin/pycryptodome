SHA-224
=======

SHA-224 belongs to the SHA-2_ family of cryptographic hashes.
It produces the 224 bit digest of a message.

    >>> from Crypto.Hash import SHA224
    >>>
    >>> h = SHA224.new()
    >>> h.update(b'Hello')
    >>> print(h.hexdigest())

If the whole message is available at once, :func:`Crypto.Hash.SHA224.digest`
returns the digest with a single call, which is faster for short messages::

    >>> print(SHA224.digest(b'Hello').hex())

*SHA* stands for Secure Hash Algorithm.

.. _SHA-2: http://nvlpubs.nist.gov/nistpubs/FIPS/NIST.FIPS.180-4.pdf
